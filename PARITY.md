# Parity with the Mac app

This is the Windows port of [Term Organize](https://github.com/AlexmChadwick/Northeastern-Term-Organize) (SwiftUI). Logic is in `src/TermOrganize.Core`. The shell is `src/TermOrganize.App` (WinUI 3, Mica, light and dark). Each row was checked against the Swift sources and the C# that is in this tree.

The core library was built and tested on Linux (.NET 9): `dotnet test` passed 298 tests, 0 failed, including the live Banner term-list smoke test. `dotnet build TermOrganize.sln` succeeded on Linux. On Linux the WinUI project is an empty stub (`EnableDefaultCompileItems` is false), so that build does not compile XAML or the shell. The WinUI project was not compiled or run on Windows here. `.github/workflows/windows.yml` is the Windows build, test, MSIX, and unpackaged zip. It runs on push, pull request, and `workflow_dispatch`. Pushing `main` is the trigger. This environment’s only git remote is Origin. After the push, `origin pr list` reported that the repository was not found, so no windows-latest run could be started or watched from here.

## Tests

Swift tests under `NEUClassSearchTests` were ported to xUnit in `tests/TermOrganize.Core.Tests`: models, search, Banner parsers, the catalog, schedules (generator, preferences, blockers, brute force), degree-plan text and PDF, the degree audit and NUpath fixtures, random audit matching, attribute lookup, watchlist, rooms, professors, cloud-sync merge, the preference parser, and the term, catalog-cache, calendar-draft, offering-history, and seat-check helpers. On Linux, `dotnet test` of that project passed (298 tests, 0 failed).

## Not the same

- Rooms have no day timeline or per-room inspector. Professors and watchlist are lists, not the Mac detail windows. Search results are not the Mac course table. Courses open in the search pane.
- Degree courses are not drag-reordered. Move suggestions apply a computed move. Print opens the View Plan PDF.
- Widgets Board, EventKit, and a signed-in iCloud account are not implemented. Windows Calendar is the Appointments API, with an .ics fallback.
- Catalog files this port saves are gzip. It still opens the Mac `.catalog` format.
- The WinUI shell, the background COM server, Task Scheduler, toasts, and the Appointments API were reviewed against the WinUI and Windows App SDK contracts and were not compiled or run on Windows in this environment.
